# Первый уровень — Bounce Back

Готовый проект для Godot 4.7.2. Боковой персонаж использует твои анимации; оригинальные PNG, GG.tres, GG.tscn и материалы вида сверху оставлены без изменений.

## Запуск

1. Если этот проект уже открыт в Godot, закрой его и открой снова, чтобы загрузились новые настройки запуска.
2. Открой `project.godot` в папке `bounce-back-game`. Для версии из архива сначала распакуй архив, затем в менеджере проектов Godot нажми **Импортировать** и выбери `project.godot` внутри папки `BounceBack-Level01`.
3. Дождись импорта изображений и нажми **F5**. Кнопка ▶ в правом верхнем углу делает то же самое.
4. Если клавиши не реагируют, щёлкни внутри окна запущенной игры.

## Управление

- **A / ←** — влево.
- **D / →** — вправо.
- **W / ↑ / пробел** — прыжок. Удерживай для полного прыжка; короткое нажатие даёт небольшой прыжок.
- **R** — начать уровень заново.
- Доберись до двери справа. После победы можно нажать **Enter** или кнопку **Ещё раз**.

Клавиши A/D/W назначены по физическому расположению и работают при русской раскладке.

## Звук и небольшие анимации

- Персонаж и дверь увеличены примерно на 15%; коллизии подстроены под новый размер.
- Из двух труб непрерывно выходят заметные мягкие клубы пара. Цепи медленно качаются с размахом около 8 пикселей.
- Подключены твои три файла: `audio/death.mp3` — смерть, `audio/walk.mp3` — шаги, `audio/jump.mp3` — прыжок.
- Шаги играют только во время движения по полу и останавливаются при остановке, прыжке, смерти и победе.
- Звук прыжка срабатывает только при настоящем прыжке, а звук смерти — один раз за попытку.
- Громкость можно настроить в сцене `scenes/player.tscn`: выдели **DeathSound / WalkSound / JumpSound** и измени **Volume dB** в Инспекторе. Чем больше значение, тем громче. Текущие значения: смерть +16 dB, шаги +12 dB, прыжок −4 dB. Они компенсируют разную громкость исходных записей.
- На общей шине Master установлен ограничитель резких пиков до −1 dB, чтобы одновременные звуки не перегружали выход.
- Для силы пара выдели **LevelAmbience → Steam Opacity**. Настройки покачивания цепей находятся у **Background → Material → Shader Parameters**.

## Что сделано

- Боковой персонаж: ожидание, бег, прыжок, падение, разворот влево и вправо.
- Пол и границы с физическими коллизиями, совпадающими с рисунком.
- Две группы шипов с треугольными зонами смерти.
- Невидимый триггер над скрытой ямой. Когда персонаж до него доходит, открывается яма из второй картинки и исчезает твёрдый участок пола. После срабатывания яма остаётся открытой до перезапуска.
- Шипы в яме убивают; через 0,65 секунды персонаж появляется в начале, а пол восстанавливается.
- Доходить до ямы обычным бегом опасно. Чтобы пройти её, прыгай заранее и удерживай прыжок.
- Счётчик смертей и завершение уровня у двери.

Исходные картинки имеют размеры 1280×720 и 960×540. Для открытой ямы используется только соответствующий фрагмент второго рисунка с масштабом 4/3: остальной фон при срабатывании остаётся неподвижным.

## Где менять поведение

Все важные параметры доступны в Инспекторе Godot, писать код для настройки не обязательно.

- Открой `scenes/level_01.tscn` — это первый уровень и стартовая сцена проекта.
- Выдели **Player**: `Speed` — скорость, `Jump Velocity` — начальная скорость прыжка (более отрицательное число даёт более высокий прыжок), `Gravity` — гравитация.
- Выдели **HiddenPit**: `Trigger X` — горизонтальное положение невидимой точки срабатывания. Сейчас это x=1003 в координатах рисунка 1280×720.
- Выдели **Level01**: `Respawn Delay` — задержка перед новой попыткой.
- Узлы **SpikesLeft / SpikesRight** содержат треугольники столкновений шипов. В редакторе включи видимость коллизий для их просмотра.
- Для отладки во время игры: меню **Отладка → Видимые формы столкновений**.

## Файлы кода

- `scripts/player.gd` — движение, анимации, смерть и восстановление персонажа.
- `scripts/hazard.gd` — смерть при касании опасности.
- `scripts/hidden_pit.gd` — открытие ямы и восстановление пола.
- `scripts/level_01.gd` — начало уровня, счётчик смертей, возрождение и выход.
- `resources/side_frames.tres` — отдельные боковые анимации со стабильным положением ног. Они используют оригинальные изображения и не зависят от старого кэша вида сверху.
- `scripts/level_ambience.gd` — лёгкий пар из труб.
- `shaders/level_background.gdshader` — медленное движение цепей и увеличение двери без изменения исходной картинки.

## Проверка

Проект проверен в Godot 4.7.2: 25 автоматических проверок настоящей физики без ошибок. Проверены движение, прыжок без двойного прыжка, обе группы шипов, открытие ямы, падение, восстановление пола, прыжок через яму, финиш и повтор. Также проверен внешний вид закрытой ямы, открытой ямы и экрана победы в графическом режиме.

После обновления повторно проверена физика с увеличенным персонажем, а также запуск звуков, отключение шагов в воздухе и на месте, отсутствие повторного звука прыжка в воздухе и зацикливание шагов дольше длительности исходной записи.
